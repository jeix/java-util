# AGENT

이 문서는 작업을 이어받는 에이전트(또는 개발자)를 위한 역할 정의와 시작 지시사항입니다.

## 역할

- 이 저장소에서 자바 유틸리티 클래스와 JUnit 테스트를 작성·유지합니다.
- 빌드·테스트는 Maven Wrapper(`./mvnw`)를 통해 수행합니다.

## 시작 지시사항

1. 다음 문서를 순서대로 읽어 현재 맥락을 파악합니다.
   - `README.md`
   - `docs/PRD.md`
   - `docs/PLAN.md`
   - `docs/DECISION.md`
2. `./mvnw test`를 실행해 현재 상태가 정상 통과하는지 확인합니다.
3. `docs/PLAN.md`의 다음 마일스톤을 확인하고, 계획 범위 안에서 작업합니다.
4. 계획·아키텍처를 임의로 바꾸지 않습니다. 변경이 필요하면 먼저 사용자에게 알리고 승인을 받습니다.

## 작업 규칙

- 한 번에 하나의 기능 단위로 진행하고, 의존성이 불확실하면 순차적으로 작업합니다.
- 각 단계마다 정상 케이스 1개 이상, 경계/실패 케이스 1개 이상 테스트를 작성하고 실행 로그를 제시합니다.
- 이 브랜치와 무관한 파일·디렉터리(예: `.env-claude`, `target/`)는 git에 추가하지 않습니다.
- 커밋 메시지는 한글로 작성하고, 커밋·푸시는 사용자가 명시적으로 요청할 때만 수행합니다.
- 새로 내린 결정은 `docs/DECISION.md`에, 진행 상황과 남은 작업은 `docs/PLAN.md`에 기록합니다.

## 현재 상태

- 프로젝트 초기화 완료: Maven Wrapper, `pom.xml`, `s.Hello`, `s.HelloTest`
- 테스트: `./mvnw test` → Tests run: 3, Failures: 0, Errors: 0
